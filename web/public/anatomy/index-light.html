Address type

Links and treasuryEach link is a random 22-character token, shown once; Cachet stores only its SHA-256 fingerprint. Creating links moves no funds. The Ironwood treasury targets four notes so payouts can go back to back.

Address checkTransparent, Sapling-only and wrong-network addresses are refused. A unified address on the right network must contain an Orchard receiver.

PaymentExample payout: 20,000 zats plus a 10,000-zat fee, with an encrypted memo. The observed on-chain v6 transaction had 0 transparent, 0 Sapling, 0 Orchard, 2 Ironwood actions; only the fee was public.

Confirmation and expiryPaid means confirmed in a block; the stored address is then deleted. Typical blocks: 75 s mainnet, 25 s NU7 testnet, about 8 s regtest demo. Unclaimed links expire after 1–90 days and their funds stay in the treasury. Animation is compressed.
